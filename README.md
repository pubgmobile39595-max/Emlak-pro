# 🏠 EmlakPro

Türkiye'nin her yerinden emlak ilanları platformu.

## ✨ Özellikler

- 🏘️ İlan listeleme + filtreler
- ❤️ Favoriler
- 🌙 Karanlık/Aydınlık tema
- 📱 İlan detay modalı
- ➕ İlan ekleme (81 il)
- 📸 Resim yükleme
- 🗺️ Harita (Leaflet)
- 👤 Kullanıcı girişi
- 💬 Mesajlaşma
- 📊 Admin panel
- ⭐ İlan puanlama
- 🔔 Bildirimler
- 🌍 Çoklu dil (TR/EN)
- 🔍 Gelişmiş arama
- 💰 Kredi hesaplama
- 📱 PWA

## 🛠️ Teknolojiler

- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js
- Veritabanı: JSON
- Harita: Leaflet + OpenStreetMap
- PWA: Service Worker

## 🚀 Kurulum

git clone https://github.com/pubgmobile39595-max/emlakpro.git
cd emlakpro
node server.js

Tarayıcıda: http://localhost:3000
